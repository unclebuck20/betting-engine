Fair line = the sharpest available book (Pinnacle first) with the bookmaker's cut removed. Confidence = chance this side covers at the listed number, capped at the best rate the model has shown in backtests. College picks use in-season power ratings (CollegeFootballData); NFL picks use opponent-adjusted unit and QB ratings from every play since 2013 (nflverse), trusted only where the 2017-25 backtest beat the closing line (4+ pt disagreements), plus injury news the sharp line hasn't absorbed (ESPN). Closing-line value (CLV) = how your number compares with the fair line at kickoff; it's the fastest honest read on whether picks are good. Source
